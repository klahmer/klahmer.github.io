# Tawasul Media — web estática

Versión inicial de una página sencilla, adaptable a móvil y lista para GitHub Pages. No necesita instalar dependencias.

## Publicar en GitHub Pages

1. Crea un repositorio público llamado `tawasul-media` (o el nombre que prefieras).
2. Sube `index.html` y este `README.md` a la rama principal.
3. En el repositorio abre **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y `/ (root)`, y guarda.
5. GitHub mostrará la dirección pública de la página. Para que la dirección sea `usuario.github.io`, el repositorio debe llamarse exactamente `usuario.github.io`.

Los enlaces a YouTube, Facebook, Verkami y las dos publicaciones externas ya están incluidos. Conviene revisar que las fotos, las cuentas de Instagram/X/TikTok y los datos de contacto que se quieran mostrar sean los definitivos antes de añadirlos.
